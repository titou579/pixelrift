# 🌌 PIXELRIFT

Mini-FPS multijoueur entre potes — style Nova Low-Poly, mécanique signature : le Rift.

## Stack
- Frontend : React + Vite + Three.js
- Backend : Node + Express + Socket.io
- Hébergement : Render (free tier) + UptimeRobot

## Dev local
```bash
# Terminal 1 — backend
cd server && npm install && npm run dev

# Terminal 2 — frontend
cd client && npm install && npm run dev
